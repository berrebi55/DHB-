# 🚀 Feuille de route de lancement — DHB (ta démarche à toi)

> Ce document liste **tes démarches** (hors code/site). Pour le **juridique et le fiscal**,
> fais valider par un **expert-comptable** (et un juriste pour les contrats).
> Moi (l'IA) je m'occupe de tout le digital ; toi des démarches administratives et commerciales.

---

## Phase 1 — Créer l'entreprise (fondations légales) — *priorité absolue*
- [ ] **Choisir le statut** : micro-entreprise (simple pour démarrer) ou société (SASU/EURL, plus crédible, mieux pour grandir). → **expert-comptable**.
- [ ] **Immatriculer** l'entreprise (guichet unique INPI) → obtenir le **SIRET**.
- [ ] **Compte bancaire professionnel**.
- [ ] **Assurance RC Pro** (Responsabilité Civile Professionnelle) — **indispensable** en informatique (si perte/corruption de données client, litige).
- [ ] *(Pour les particuliers)* **Déclaration « Services à la Personne »** → ouvre le **crédit d'impôt 50 %** à tes clients particuliers (l'assistance informatique à domicile est éligible). Argument commercial énorme. Sous conditions — à vérifier.

## Phase 2 — Identité & conformité
- [ ] Finaliser **logo, marque, signature**.
- [ ] Réserver les **noms de domaine** (groupe, pro, particuliers).
- [ ] **Email professionnel** (Microsoft 365 ou Google Workspace).
- [ ] Compléter **mentions légales** (SIRET, forme juridique, siège, hébergeur) + **politique de confidentialité** (RGPD).
- [ ] **RGPD « sous-traitant »** : tu traites les données de tes clients → prévoir un **contrat de sous-traitance (DPA)**, un registre, des mesures de sécurité.

## Phase 3 — Outils & fournisseurs (ton « matériel » de travail)
- [ ] **NinjaOne** (supervision) — abonnement + espace client → récupérer le **lien** à mettre sur le site.
- [ ] **Antivirus / EDR** professionnel (compte revendeur).
- [ ] **Solution de sauvegarde** (hébergée en Europe pour le RGPD).
- [ ] **Microsoft 365 / Google Workspace** : devenir **partenaire/revendeur (CSP)** si tu veux vendre les licences.
- [ ] **Stripe** (paiement particuliers) + **Resend** (emails automatiques) → me donner les clés.
- [ ] **Hébergement** des sites (Cloudflare Pages = gratuit) ; VPS Hetzner seulement si tu veux un serveur d'automatisations.
- [ ] **Facturation conforme** (règles anti-fraude TVA) → valider notre module factures avec le comptable, ou prendre un logiciel dédié.

## Phase 4 — Offre, prix, contrats
- [ ] Finaliser les **offres** : infogérance (forfaits par poste) · particuliers (abonnement + intervention).
- [ ] Fixer tes **prix définitifs** selon **tes coûts réels** (on a fait l'étude de marché).
- [ ] Préparer tes **modèles** : devis, **contrat d'infogérance** (périmètre, délais/SLA, réversibilité), **CGV**, contrat d'abonnement particulier, charte d'engagement.
- [ ] Définir tes **délais réellement tenables** (pour les garanties affichées sur le site).

## Phase 5 — Mise en ligne & présence
- [ ] Publier les **3 sites** + brancher les **vrais domaines**.
- [ ] Créer ta **fiche Google Business Profile** (Google Maps) — **essentiel** pour le local IdF.
- [ ] Créer les **profils réseaux** (LinkedIn pour le pro ; Insta/Facebook pour les particuliers).
- [ ] Soumettre les **sitemaps** à **Google Search Console**.

## Phase 6 — Acquisition (trouver des clients)
- [ ] Activer le **SEO** (déjà en place) + suivi Search Console.
- [ ] **Lead magnets + séquences email** automatiques (on les construit ensemble).
- [ ] **Partenariats prescripteurs** : experts-comptables, agences web, vendeurs de matériel, syndics…
- [ ] **Programme de parrainage**.
- [ ] *(Optionnel)* **Publicité** Google/Meta pour amorcer les premiers leads.
- [ ] Démarchage **local** : commerces, cabinets, associations du quartier.

## Phase 7 — Opérationnel (quand les clients arrivent)
- [ ] Processus d'**intervention** : prise de RDV, **accès à distance sécurisé**, compte-rendu.
- [ ] **Support** : un canal clair (tickets déjà dans l'admin).
- [ ] **Onboarding client** : audit → documentation du parc → sauvegarde + sécurité en place.
- [ ] **Facturation** + **relances** (déjà dans l'admin).
- [ ] **Supervision & sauvegardes** des clients (NinjaOne).

## Phase 8 — Preuve sociale & pilotage
- [ ] Après chaque mission : **demander un avis Google** (automatisable) + créer un **cas client** anonymisé.
- [ ] Suivre tes **indicateurs** (leads, taux de transformation, CA) dans l'admin.
- [ ] Améliorer en continu.

---

## 🧭 Ordre de priorité si tu démarres de zéro
1. **Statut + SIRET + RC Pro + compte pro** (sans ça, pas de facture légale).
2. **Domaines + email pro + mentions légales**.
3. **Outils essentiels** (sauvegarde, antivirus, NinjaOne, Stripe/Resend).
4. **Offres / prix / contrats** finalisés.
5. **Mise en ligne + Google Business Profile**.
6. **Acquisition** (SEO, partenariats, emails auto).
7. **Premiers clients → avis**.

## 👥 Qui fait quoi
- **Moi (IA)** : sites, admin, emails automatiques, SEO, automatisations, contenus, guides.
- **Toi** : démarches administratives, choix du statut, contrats (à faire valider), prix définitifs, outils/comptes (NinjaOne, Stripe, Resend…), relation client.
- **Ton comptable / juriste** : statut, fiscalité, TVA, conformité des factures, contrats.
